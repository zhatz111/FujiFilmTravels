# 02 — Architecture

## Overview

```
 Your photo exports ──► Python pipeline ──► photos/out/*.webp ──► Cloudflare R2 (img.[DOMAIN])
 (photos/inbox)          (local, on demand)  data/*.json ───────► SvelteKit build ──► Cloudflare static hosting ([DOMAIN])
                                                                       │
 Visitors' browsers ◄── HTML/JS/CSS + JSON ◄────────────────────────────┘
        │
        ├── images from R2 (custom domain, cached at edge)
        ├── vector map tiles from OpenFreeMap
        └── elevation tiles (for contours) from a public DEM tileset
```

There is no backend and no database. Adding photos means: run the pipeline, commit the updated JSON, push. The site rebuilds automatically.

```

      map/

      components/

```

Use Svelte 5 runes. Keep MapLibre inside `Globe.svelte`; the rest of the app talks to it through the state object only (state changes → camera/layer updates; map clicks → state changes).

## URL scheme

Query params on `/` so the page stays a single prerendered file:

| Level | URL |
|---|---|
| World | `/` |
| Country | `/?c=argentina` |
| Spot | `/?c=argentina&s=el-chalten` |
| Photo open | `/?c=argentina&s=el-chalten&p=2026-03-14-a1b2c3` (or `/?c=japan&p=…` when filtered to country) |
| Filters (any level) | `who=<person>` traveler, `trip=<visit-id>` one trip (see `08-build-plan.md`, Phase 4.6) |

`state.svelte.ts` reads the URL on load and pushes history entries on navigation (`replaceState` for lightbox prev/next, `pushState` for level changes).

## Data contract (`/data`)

Generated by the pipeline, committed to git, imported by the site at build time. Schemas are in `04-photo-pipeline.md`; examples in `/data/*.example.json`.

- `photos.json` — one entry per published photo.
- `spots.json` — clusters of photos with a name, center, radius, and country.
- `countries.json` — visited countries with center, camera zoom, photo/spot counts, cover photos.
- `people.json` — hand-edited list of people (photographers and companions).
- `trips.json` — hand-edited list of planned trips (validated by `uv run pipeline trips`).
- `visited-countries.geojson` — simplified Natural Earth polygons for visited countries only (for tints).

## Images

- Derivatives are named by content hash, e.g. `p/a1b2c3d4e5-480.webp`, `-1600.webp`, `-2560.webp`. Immutable, cached for a year.
- `<img>` tags use `srcset` with the 480/1600 sizes, `loading="lazy"`, `decoding="async"`, explicit `width`/`height` to prevent layout shift.
- A tiny dominant color per photo (from the pipeline) is used as the tile background while loading.

## Third-party services (all free, no API keys)

- OpenFreeMap vector tiles and styles (`https://tiles.openfreemap.org`).
- Public DEM tiles in Terrarium encoding for contours (AWS Open Data "Terrain Tiles"). If unavailable, fall back to another free Terrarium/Terrain-RGB source; contours are progressive enhancement.
- Natural Earth (public domain) for visited-country polygons, processed by the pipeline.

Credit OpenFreeMap, OpenMapTiles, and OpenStreetMap contributors in the map attribution control.
