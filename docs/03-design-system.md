# 03 — Design system: Alpine Morning

Misty mountain morning: cool mist-green ground, pine greens, a warm sunrise orange for accents, topo-map browns for elevation. Calm, light, editorial. All values below come from the approved mockup (`reference/mockup-alpine.html`).

## Color tokens (`src/lib/styles/tokens.css`)

> `tokens.css` is generated by `site/scripts/gen_tokens.py` (run `python site/scripts/gen_tokens.py`, then `pnpm --dir site format`): it holds the
> Alpine Morning palette below plus an **Alpine Night** palette for dark mode, registers every color with
> `@property` so theme changes interpolate, and staggers them (page dims, then sky as the sun sets, then
> the ridges) to choreograph the day ↔ night transition. The map's night palette is in `map/style.ts`.

## Layout

- Max content width 1440px, page padding 28px top / 32px sides, 64px bottom. Section gap 32px.
- Globe section: flex-wrap row. Stage `flex: 999 1 620px`, height 640px (desktop), 480px (≤ 720px wide). Panel `flex: 1 1 300px`, padding 28px 24px, left border `--line`.
- Gallery grid: CSS columns `columns: 4 240px; column-gap: 16px`, tiles `break-inside: avoid; margin-bottom: 16px`.
- Country cards: `grid-template-columns: repeat(auto-fill, minmax(220px, 1fr)); gap: 20px`.

## Components

- **Destination row / Spot row:** button, min-height 56/52px, `--surface` bg, 1px `--line` border, radius 10. Name left (Karla 17/600), mono coords under it, count right in `--pine`. Active spot row: `--pine` bg, white text.
- **Upcoming trip row:** same shape, 1px dashed `--upcoming-line` border, `--upcoming-soft` bg, blue ring icon, date range in mono, countdown ("in 95 days") right in `--upcoming`.
- **Filter chips:** pill, min-height 44, 1px `--line` border, transparent; active = `--pine` bg + white text; count in mono at 80% opacity. Use `aria-pressed`.
- **Breadcrumb:** glass chip top-left of stage, mono 12 uppercase; current level `--ink`, ancestors `--muted`, "/" separators `--faint`.
- **Hint pill:** glass pill bottom-center, mono 11 uppercase, 0.12em tracking.
- **Legend:** glass box bottom-left above the hint; three rows (green dot with white border + soft ring, blue 2.5px ring, orange dot).
- **Live banner:** pill under the hero paragraph: `--live-soft` bg, `--live-line` border, green dot with CSS pulse ring, "Currently in X" bold + "· through Oct 16", trailing mono "SHOW ON GLOBE →".
- **Photo tile:** button, `--surface` bg, 1px `--line` border, radius 10, 6px padding; image radius 6 with intrinsic aspect ratio; caption row: spot name (Karla 14/600) + mono coords.
- **Country card:** button, 10px padding; collage of 3 cover photos (one tall left, two stacked right) at 4:3; name 18/600; mono meta "4 spots · 22 photos".
- **Lightbox (PhotoSwipe custom UI):** `--lightbox-bg`, image with `--shadow-lightbox`, round 44–48px prev/next/close buttons with 1px borders, info sidebar per `01-product-spec.md`.

## People components

- **Person palette** (assign in order in `people.json`; all pass 3:1 against white initials at 13px bold and read on the map): `#2D5A43` pine, `#B4551A` sunrise, `#3F6F86` slate, `#7A4E8C` heather, `#9C6B1F` ochre, `#2F7F86` teal, `#A23E48` berry, `#5B6B2F` moss.
- **Avatar:** 32px circle (24px in stacks and tile badges, 40px in the people menu), person color fill, white Karla 13/700 initials, 2px `--surface` ring so stacked avatars separate. Photo avatars use the same ring.
- **Avatar stack:** overlap −8px, max 4 then a "+n" circle in `--line` with `--ink` text.
- **Filter bar:** full-width box above the globe section, `--surface` bg, 1px `--line` border, radius 14, padding 16×20. Each filter is a `<label>` (mono 11 uppercase, 0.14em tracking, `--muted`) wrapping a `<select>` (min-height 44, min-width 200–240, white bg, 1px `--line`, radius 10, Karla 16/600). Right side: result line (mono 13, `--pine`) and a "Clear filters" pill button shown only when a filter is active. Wraps to stacked rows on phones.
- **Trip card (panel, display only):** white bg, 1px `--line`, radius 10, padding 14; date range (Karla 16/700) with photo count (mono 12, `--pine`) on the right; label in `--muted`; avatar stack (28px) followed by names ("Zach, Alex & Sam").
- **Gallery trip heading:** Fraunces 22/600 date ("March 2025") + `--muted` label + avatar stack, 1px `--line` rule below.
- **Photographer badge on tiles:** 24px avatar at the image's bottom-left, 8px inset.

## Stage decoration (behind the globe, decorative, `aria-hidden`)

- Pale sun: 160px circle, `--sun`, 90% opacity, top 70px, right 12%.
- Three layered mountain ridgelines as one inline SVG pinned to the stage bottom, height 300px, fills `--ridge-1..3` back to front. Copy the paths from the mockup.
- With MapLibre's globe, set the map container background transparent and the style's `sky`/background so the stage gradient shows around the globe.

## Motion

- Camera transitions per `05-map-and-globe.md`. Pin drop-in: each photo pin falls 60px with ease-out over 420ms, staggered 90ms.
- Live pulse: two rings expanding 7→33px radius, fading out, 1.8s loop, offset by half a cycle.
- Hover on rows/tiles: background tint or 1px border darken only, 120ms. No scale bounces.
- `prefers-reduced-motion: reduce` disables auto-spin, pulse, pin drop, and makes camera moves instant.

## Accessibility

- Text contrast ≥ 4.5:1 (≥ 3:1 for 24px+). `--faint` is never used for text.
- Focus ring: `outline: 2px solid var(--pine); outline-offset: 3px` on all interactive elements.
- Touch targets ≥ 44px.
- The map canvas gets `aria-label` describing it and that the destination list offers the same navigation.
